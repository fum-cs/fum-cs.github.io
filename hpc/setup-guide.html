🐧 نصب و پیکربندی WSL2

۱ فعال‌سازی WSL

در PowerShell (با دسترسی ادمین) اجرا کنید:

wsl --install -d Ubuntu

پس از نصب، سیستم ری‌استارت می‌شود. پس از ری‌استارت، Ubuntu باز می‌شود و از شما نام کاربری و رمز عبور می‌خواهد.

۲ تنظیم WSL2 به‌عنوان پیش‌فرض 
wsl --set-default-version 2
۳ تنظیم حافظه و پردازنده

فایل .wslconfig را در مسیر زیر ایجاد/ویرایش کنید:

C:\Users\amin\.wslconfig
[wsl2]
memory=24GB
processors=6
swap=16GB
swapFile=D:\\temp\\wsl-swap.vhdx
localhostForwarding=true
⚠️ نکته: مقدار memory را بر اساس RAM سرور تنظیم کنید. برای سرور با ۳۲GB RAM، مقدار ۲۴GB مناسب است (۸GB برای سیستم‌عامل باقی می‌ماند).
۴ بروزرسانی Ubuntu و نصب ابزارها 
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git build-essential cmake pkg-config
✅ تست: اجرا کنید wsl -l -v — باید Ubuntu با نسخه ۲ نشان داده شود.

🐳 نصب و پیکربندی Docker Desktop

۱ دانلود و نصب Docker Desktop

از سایت رسمی دانلود کنید.

  1. فایل نصب را اجرا کنید

  1. گزینه "Enable integration with my default WSL distro" را فعال کنید

🤖 نصب Ollama

۱ دانلود Ollama

از سایت رسمی یا آینه git.ir دانلود کنید:

۲ نصب Ollama
  1. فایل نصب را اجرا کنید
  2. مسیر نصب: پیش‌فرض (C:\Users\<نام_کاربری>\AppData\Local\Programs\Ollama)

⚠️ روش استفاده:
  • کاربران LDAP: با نام کاربری و رمز عبور دانشگاه وارد می‌شوند (خودکار)

c.NativeAuthenticator.minimum_password_length = 8

🔗 LDAP Connection

💡 اطلاعات سرور LDAP دانشگاه:
پارامتر مقدار
آدرس سرور 172.20.9.29
پورت 389
دامنه SAD
Base DN DC=SAD,DC=UM,DC=AC,DC=IR
الگوی Bind DN SAD\{username}
⚠️ چرا به پروکسی نیاز است؟
  • کانتینرهای Docker Desktop نمی‌توانند مستقیماً به سرور LDAP دانشگاه متصل شوند
  • پروکسی LDAP روی میزبان WSL اجرا می‌شود و ترافیک LDAP را انتقال می‌دهد
  • کانتینرها از طریق IP میزبان WSL به پروکسی متصل می‌شوند
۱ پیدا کردن IP میزبان WSL 
# در WSL:
hostname -I | awk '{print $1}'

# یا بررسی IP دروازه Docker:
docker network inspect bridge | grep Gateway
💡 IP رایج میزبان WSL: 172.28.148.211 (ممکن است تغییر کند)
۲ تست اتصال LDAP 
# تست مستقیم به AD دانشگاه:
ldapsearch -x -H ldap://172.20.9.29 -b "DC=SAD,DC=UM,DC=AC,DC=IR" -D "SAD\username" -W "(sAMAccountName=username)"

# تست از طریق پروکسی (پس از راه‌اندازی):
ldapsearch -x -H ldap://localhost:1389 -b "DC=SAD,DC=UM,DC=AC,DC=IR" -D "SAD\username" -W "(sAMAccountName=username)"
۳ ایجاد و راه‌اندازی LDAP Proxy 
# فایل proxy در: ~/jupyterlab-gpu/ldap_proxy.py
# راه‌اندازی:
nohup python3 ~/jupyterlab-gpu/ldap_proxy.py > /tmp/ldap_proxy.log 2>&1 &

نصب Tailscale (دسترسی از خارج)

۱ دانلود و نصب

از سایت رسمی یا لینک دانشگاه دانلود و نصب کنید.

۲ ثبت‌نام و اتصال
  1. با ایمیل دانشگاهی ثبت‌نام کنید
  2. دعوت‌نامه را از این لینک بپذیرید
  3. اتصال را تأیید کنید
۳ تنظیم نام دستگاه

در پنل Tailscale، نام دستگاه را به math-gpu-server تغییر دهید تا آدرس ثابت باشد.

💡 نکته: استفاده از نام دستگاه به جای IP توصیه می‌شود، زیرا IP ممکن است تغییر کند. نام دستگاه ثابت است و تغییر نمی‌کند.
⚠️ نکته مهم:
  • هر دستگاهی که به شبکه Tailscale متصل می‌شود، یک IP منحصربه‌فرد دریافت می‌کند.
  • آدرس نام دستگاه ثابت است و تغییر نمی‌کند.
  • اگر با نام دستگاه به مشکل خوردید، IP صحیح سرور را از پنل مدیریت Tailscale پیدا کنید.
