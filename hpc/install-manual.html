📌 این راهنما برای چه کسی است؟
  • افرادی که مسئولیت نگهداری سرویس‌های HPC (JupyterHub، code-server، مدل‌های زبانی) را بر عهده دارند.

🐧 نصب WSL2

۱ فعال‌سازی WSL

در PowerShell (با دسترسی ادمین) اجرا کنید:

wsl --install -d Ubuntu

پس از نصب، سیستم ری‌استارت می‌شود. پس از ری‌استارت، Ubuntu باز می‌شود و از شما نام کاربری و رمز عبور می‌خواهد.

۲ تنظیم WSL2 به‌عنوان پیش‌فرض 
wsl --set-default-version 2
۳ تنظیم حافظه و پردازنده

فایل .wslconfig را در مسیر زیر ایجاد/ویرایش کنید:

C:\Users\<نام_کاربری>\.wslconfig
[wsl2]
memory=24GB
processors=6
swap=16GB
swapFile=D:\\temp\\wsl-swap.vhdx
localhostForwarding=true
nestedVirtualization=true
⚠️ نکته: مقدار memory را بر اساس RAM سرور تنظیم کنید. برای سرور با ۳۲GB RAM، مقدار ۲۴GB مناسب است (۸GB برای سیستم‌عامل باقی می‌ماند).
۴ بروزرسانی Ubuntu 
sudo apt update && sudo apt upgrade -y
۵ نصب ابزارهای پایه 
sudo apt install -y curl git build-essential cmake pkg-config
✅ تست: اجرا کنید wsl -l -v — باید Ubuntu با نسخه ۲ نشان داده شود.

🐳 نصب Docker Desktop

۱ دانلود Docker Desktop

از سایت رسمی دانلود کنید یا از فایل موجود در درایو D:

# اگر فایل نصب در درایو E موجود است:
# "E:\downloads\Docker Desktop Installer.exe"
۲ نصب Docker Desktop
  1. فایل نصب را اجرا کنید
  2. گزینه "Use WSL 2 instead of Hyper-V" را انتخاب کنید
  3. گزینه "Add shortcut to desktop" را فعال کنید
  4. صب را انجام دهید و سیستم ری‌استارت کنید
۳ تنظیم Docker Desktop

پس از نصب، Docker Desktop را باز کنید و به Settings → Resources → WSL Integration بروید:

  1. گزینه "Enable integration with my default WSL distro" را فعال کنید
  2. Ubuntu را از لیست انتخاب کنید
  3. Apply و Restart را بزنید
۴ انتقال داده‌های Docker از C به D

برای صرفه‌جویی فضا در درایو C، داده‌های Docker را به درایو D منتقل کنید:

  1. Docker Desktop را ببندید
  2. در PowerShell (ادمین):
# ایجاد پوشه مقصد
mkdir D:\DockerData\DockerDesktopWSL

# ویرایش تنظیمات Docker Desktop
# فایل زیر را با Notepad باز کنید:
notepad "C:\Users\<نام_کاربری>\AppData\Roaming\Docker\settings-store.json"

# مقدار زیر را اضافه/ویرایش کنید:
# "CustomWslDistroDir": "D:\\DockerData\\DockerDesktopWSL"
💡 نکته: پس از تغییر این تنظیم، Docker Desktop را مجدداً راه‌اندازی کنید تا تغییرات اعمال شود.
✅ تست: در WSL اجرا کنید docker run hello-world — باید پیام موفقیت نمایش داده شود.

🤖 نصب Ollama

۱ دانلود Ollama

از سایت رسمی یا آینه git.ir دانلود کنید:

# روش ۱: سایت رسمی (اگر اینترنت بین‌الملل دارید)
# فایل نصب از https://ollama.com/download

# روش ۲: آینه git.ir (سریع‌تر در ایران)
# فایل: https://cdn12.git.ir/softwares/ollama/ollama-windows-amd64.exe
۲ نصب Ollama
  1. فایل نصب را اجرا کنید
  2. مسیر نصب: پیش‌فرض (C:\Users\<نام_کاربری>\AppData\Local\Programs\Ollama)
  3. Ollama پس از نصب خودکار اجرا می‌شود
۳ دانلود مدل‌ها

مدل‌ها را از درایو D (نسخه پشتیبان) کپی کنید یا مجدداً دانلود کنید:

# روش ۱: کپی از درایو D (سریع‌تر)
# مدل‌ها در: D:\ollama\models
# کپی به: C:\Users\<نام_کاربری>\.ollama\models

# روش ۲: دانلود مجدد
ollama pull qwen3:8b
ollama pull qwen3:14b
ollama pull gemma3:4b
ollama pull llama3.2
💡 نکته: مدل‌های اصلی حدود ۱۰۰ گیگابایت فضا نیاز دارند. درایو D توصیه می‌شود.
۴ تنظیم مسیر مدل‌ها (اختیاری)

اگر می‌خواهید مدل‌ها در درایو D ذخیره شوند، متغیر محیطی زیر را تنظیم کنید:

# در PowerShell (ادمین):
[Environment]::SetEnvironmentVariable("OLLAMA_MODELS", "D:\ollama\models", "User")
✅ تست: ollama run qwen3:8b — یک سوال بپرسید و پاسخ بگیرید.

⚙️ راه‌اندازی سرویس‌ها

📓 JupyterHub

۱ کلون/کپی فایل‌های پیکربندی 
# در WSL:
cd ~
git clone <آدرس_مخزن> jupyterlab-gpu
# یا کپی از درایو D:
cp -r /mnt/d/jupyterlab-gpu ~/jupyterlab-gpu
۲ ساخت تصویر Docker 
# در WSL:
cd ~/jupyterlab-gpu
docker build -t jupyterhub:complete -f Dockerfile .
⚠️ زمان‌بر: ساخت تصویر ممکن است ۳۰-۶۰ دقیقه طول بکشد.
۳ ایجاد فایل .env 
# فایل ~/jupyterlab-gpu/.env:
JUPYTER_TOKEN=<توکن_امن>
JUPYTER_PORT=8888
۴ راه‌اندازی 
# در WSL:
cd ~/jupyterlab-gpu
docker compose up -d
sleep 5
docker exec -d jupyterhub bash -c 'cd /workspace && jupyterhub -f /etc/jupyterhub/jupyterhub_config.py'
✅ آدرس: http://localhost:8000

🔄 شروع خودکار سرویس‌ها

فایل اسکریپت یکپارچه

فایل Start-AllServices.ps1 در درایو D ذخیره شده است:

# مسیر فایل: D:\Start-AllServices.ps1
# راه‌اندازی خودکار تمام سرویس‌ها پس از ری‌استارت ویندوز

$ErrorActionPreference = "SilentlyContinue"

# --- Docker Desktop (با بازیابی کامل در صورت خرابی) ---
$dockerReady = $false
$checkOutput = wsl -d Ubuntu -e bash -c "docker info >/dev/null 2>&1 && echo ok" 2>$null
if ($checkOutput -match "ok") { $dockerReady = $true }

if (-not $dockerReady) {
    taskkill /f /im "Docker Desktop.exe" 2>$null | Out-Null
    taskkill /f /im "com.docker.backend.exe" 2>$null | Out-Null
    Start-Sleep -Seconds 3
    wsl --shutdown
    Start-Sleep -Seconds 3
    Stop-Service -Name "com.docker.service" -Force -ErrorAction SilentlyContinue
    Start-Sleep -Seconds 5
    Start-Service -Name "com.docker.service" -ErrorAction SilentlyContinue
    Start-Sleep -Seconds 5
    Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
    # انتظار تا آماده شدن Docker (حداکثر ۱۰۰ ثانیه)
    $retries = 0
    while ($retries -lt 20) {
        $ready = wsl -d Ubuntu -e bash -c "docker info >/dev/null 2>&1 && echo ok" 2>$null
        if ($ready -match "ok") { break }
        Start-Sleep -Seconds 5
        $retries++
    }
}

# --- Ollama ---
$ollamaRunning = Get-Process "ollama" -ErrorAction SilentlyContinue
if (-not $ollamaRunning) {
    Start-Process "C:\Users\<نام_کاربری>\AppData\Local\Programs\Ollama\ollama.exe" -ArgumentList "serve"
    Start-Sleep -Seconds 5
}

# --- JupyterHub ---
$jhRunning = docker ps --format '{{.Names}}' 2>$null | Select-String "^jupyterhub$"
if (-not $jhRunning) {
    wsl -d Ubuntu -e bash -c "
cd ~/jupyterlab-gpu
docker compose up -d 2>/dev/null
sleep 5
docker exec -d jupyterhub bash -c 'cd /workspace && jupyterhub -f /etc/jupyterhub/jupyterhub_config.py'
sleep 3"
}

# --- Open WebUI ---
$owRunning = docker ps --format '{{.Names}}' 2>$null | Select-String "^open-webui$"
if (-not $owRunning) {
    wsl -d Ubuntu -e bash -c "
docker run -d --name open-webui -p 3000:8080 \
  -e OLLAMA_BASE_URL=http://host.docker.internal:11434 \
  -v open-webui:/app/backend/data \
  --restart unless-stopped \
  docker.devneeds.ir/openwebui/open-webui:latest 2>/dev/null"
}

# --- Python Shiny ---
$shRunning = docker ps --format '{{.Names}}' 2>$null | Select-String "^shiny$"
if (-not $shRunning) {
    wsl -d Ubuntu -e bash -c "
docker run -d --name shiny -p 8050:8050 \
  --restart unless-stopped \
  shiny-custom:latest 2>/dev/null"
}

# --- Whisper ---
$whRunning = docker ps --format '{{.Names}}' 2>$null | Select-String "^whisper$"
if (-not $whRunning) {
    wsl -d Ubuntu -e bash -c "
docker run -d --name whisper -p 8501:8501 \
  --gpus all \
  --restart unless-stopped \
  whisper-app:latest 2>/dev/null"
}

# --- code-server (Lean) ---
$csRunning = docker ps --format '{{.Names}}' 2>$null | Select-String "^code-server$"
if (-not $csRunning) {
    wsl -d Ubuntu -e bash -c "~/restore-code-server.sh" 2>$null
}

Write-Host "Python Shiny:  http://localhost:8050"

تنظیم شروع خودکار

۱ فایل BAT در پوشه Startup

فایل زیر در مسیر Startup قرار دارد:

C:\Users\<نام_کاربری>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\Start-AllServices.bat
@echo off
start /min powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File "D:\Start-AllServices.ps1"
۲ تست

فایل D:\Start-AllServices.ps1 را اجرا کنید و مطمئن شوید تمام سرویس‌ها راه‌اندازی می‌شوند.

💡 نکته: اسکریپت به‌صورت خودکار Docker را در صورت خرابی بازیابی می‌کند (شامل wsl --shutdown، ری‌استارت سرویس، و اجرای مجدد Docker Desktop).
